BASILEOUS INVESTMENTS WEBSITE

FILES
- index.html  -> Main homepage
- styles.css  -> Design and colors
- script.js   -> Animated chart background
- logo.png    -> Your company logo

HOW TO OPEN
1. Double-click index.html, OR
2. Upload to Squarespace using a Code Block and Custom CSS.

HOW TO EDIT
- Change text in index.html
- Change colors in styles.css
- Adjust animation in script.js
- Replace logo.png with a new logo

SQUARESPACE SETUP
1. Design -> Custom CSS -> paste styles.css
2. Add a Code Block -> paste the body content from index.html
3. Settings -> Advanced -> Code Injection -> add script.js inside <script> tags if needed
4. Upload logo.png to your site assets
